# Frontend - Enterprise Operations Console

React + TypeScript UI for tenant operations teams.

## Includes

- Secure login flow
- Dashboard summary KPIs
- Customer management
- Product catalog management
- Subscription management
- Billing operations (run rating and billing cycle)
- Invoice visibility

## Run

```bash
cd frontend
npm install
npm run dev
```

Set API URL in `.env` using `.env.example` if required.
